## Ejecutar en desarrollo

1. Clonar repositorio
2. Ejecutar

```bash
yarn install
```

3. Tener Nest CLI instalado

```bash
npm i -g @nestjs/cli
```

4. Compilar y correr el proyecto

```bash
# desarrollo
yarn run start

# observar
yarn run start:dev

# producción
yarn run start:prod
```

5. Levantar la base de datos

```bash
docker compose up -d
```
